# ANCCI website — page preview (v1.1)

Static HTML preview of the new website for the **Andaman Nicobar Chamber of Commerce & Industry**, built by Digital Arts.

- Open **pages.html** for a list of every page: 109 public pages and 240 admin panel pages.
- The news from the Annual Report 2025-26 (49 posts) uses the real photos. Older posts (2017–2023) show labelled placeholders, because their photos come from the old WordPress site through the admin's "Import old website" tool.
- This is for design review only. Forms, login, WhatsApp OTP, AI writing and uploads work only on the real PHP website.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
