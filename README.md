# ANCCI website — page preview (v1.0)

Static HTML preview of the new website for the **Andaman Nicobar Chamber of Commerce & Industry**, built by Digital Arts.

- Open **pages.html** for a list of every page: 44 public pages and 89 admin panel pages.
- This is for design review only. Forms, login, WhatsApp OTP, AI writing and uploads work only on the real PHP website (installer package `ancci-website-v1.0.0.zip`).
- Photos are labelled placeholders. The real photos and the full text of every post come from the old WordPress site through the admin's "Import old website" tool.
- The sample event, the committee names in [brackets], the sample member and the inbox messages are sample data for the preview.
